# Frontend

React, TypeScript, and Vite frontend for KukGrade.

## Commands

Install dependencies:

```sh
npm install
```

Run checks:

```sh
npm run test
npm run lint
npm run typecheck
```

Run the development server:

```sh
npm run dev
```

Set `VITE_API_BASE_URL` to the backend origin when it is not running on `http://localhost:8000`.
