# Handoff

This file used to contain a 2026-09-17 point-in-time agent handoff. It became
materially stale as the frontend grew from a login screen into the main grading
workflow, and has been retired to prevent it competing with maintained docs.

For current work, read in this order:

1. `../AGENTS.md` - repository working and domain rules.
2. `current-system.md` - authoritative implemented state and known gaps.
3. `decision_log.md` - accepted decisions and their reasoning.
4. `api_contract.md` and `permissions.md` - HTTP and authority contracts.
5. `development-workflow.md` - verification commands and next sequence.

Use `git log` for historical branch/commit context. Do not record ephemeral
working-tree state or agent-specific instructions in this file.
